# ¡Bienvenido a Figthing Maxwell!

¡Hola! Soy David López y te doy la bienvenida a mi primer videojuego.

Este es un pequeño juego de lucha multijugador en línea donde podrás competir con tus amigos.

## ¿Cómo jugar?

Puedes jugar directamente en tu navegador visitando el siguiente enlace:
[https://david.deft.work](https://david.deft.work)

### Controles
- **Movimiento**: Teclas WASD o joystick en móvil.
- **Ataque**: Haz clic o toca a otros jugadores.

## Sobre el proyecto

Este proyecto fue creado con mucho cariño y esfuerzo, utilizando las siguientes tecnologías:
- Node.js
- Express
- WebSocket
- HTML5 Canvas

¡Espero que te diviertas!
